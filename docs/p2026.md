# 2026 408算法题解析


## 题目
(13 分) 已知二叉搜索树采用二叉链表存储,类型定义如下:

```cpp
typedef struct BSTNode{             //二叉搜索树结点
    int data;                       //保存结点的关键字值
    struct BSTNode *left,*right;    // 指向左孩子、右孩子的指针
} BSTNode;
typedef BSTNode BTNode;             // 二叉搜索树
```

对于给定的非空二叉搜索树 T(root 为指向 T 的根结点的指针) 和整数 k, 请设计尽可能高效的查找算法, void searchX(BTree root, int k), 查找 T 中其关键字值与 k 之差的绝对值最小的所有结点, 输出差值的绝对值和结点中的关键字值。要求:

(1) 给出算法的基本设计思想。(4 分)

(2) 根据设计思想, 采用 C 或 C++语言描述算法, 关键之处给出注释。(9 分)

## 解析

这个题本质就是在BST中求一个值的中序前驱与中序后继，直接使用两个辅助函数在`while`循环里面求出前驱和后继就行了，在主函数里面再判断哪个小，这样做的好处是在搜索的时候可以不用管哪个更小。

网上很多答案都是错的，这题不用遍历所有的结点，时间复杂度为$O(\log_n)$，空间复杂度是$O(1)$

最好不要用dfs，这个题不用搜索，直接按照`BST`的一条路径走就行了，`dfs`会有额外的栈内存作为函数运行时

考点就是中序的前驱与后继

代码

```cpp
#pragma once
#include "tree.h"
#include <cstdio>
#include <cmath>

int findNextUpper(TreeNode* root, int k) {
    TreeNode* cur = root;
    int successor = root->data;
    
    while (cur != nullptr) {
        if (cur->data >= k) {
            successor = cur->data;
            cur = cur->left;
        } else {
            cur = cur->right;
        }
    }
    return successor;
}

int findNextLower(TreeNode* root, int k) {
    TreeNode* cur = root;
    int successor = root->data;
    
    while (cur != nullptr) {
        if (cur->data <= k) {
            successor = cur->data;
            cur = cur->right;
        } else {
            cur = cur->left;
        }
    }
    return successor;
}


void searchX(TreeNode* root, int k) {
    int nextUpper = findNextUpper(root, k);
    int nextLower = findNextLower(root, k);

    if (nextUpper == k) {
        printf("%d %d\n", k, 0);
    } else {
        if (nextUpper - k == k - nextLower) {
            int sub = nextUpper - k;
            printf("%d %d\n", nextUpper, sub);
            printf("%d %d\n", nextLower, sub);
        } else {
            int num = nextUpper - k < k - nextLower ? nextUpper : nextLower;
            int sub = nextUpper - k < k - nextLower ? nextUpper - k : k - nextLower;
            printf("%d %d\n", num, sub);
        }
    }
}
```
